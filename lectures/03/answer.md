質問："uv run python -m app.agent --trace "LoRA とQLoRAの違いは？"
**オリジナル：講座の用語集から用語を検索し、定義と、どの回で扱うかを返す。
    AIエンジニアリングの用語や、この講座（AIE2026）に固有の言葉について
    答える前に使うこと。query には調べたい用語を1つだけ入れる（例: "LoRA"）。
回答：**LoRA**と**QLoRA**の違いは、ベースモデルの重みをそのまま使うか、量子化してさらにメモリを節約するかにあります。
* **LoRA（Low-Rank Adaptation）**: 
  事前学習済みのモデルの重みを固定したまま、重みの更新分を小さな低ランク行列（アダプタ）で表し、その部分だけを学習するPEFT（Parameter-Efficient Fine-Tuning）手法です。学習するパラメータ数を大幅に減らすことができます。
* **QLoRA（Quantized LoRA）**: 
  LoRAの仕組みに加え、ベースモデルの重みを4ビットなどの低ビットに**量子化**してメモリ消費を極限まで抑えながら、LoRAによるファインチューニングを行う手法です。これにより、より大きなモデルを比較的小さなGPUメモリでも学習できるようになります。
